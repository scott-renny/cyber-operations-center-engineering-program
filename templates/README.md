# Operational Documentation Templates

Use these templates for COC runbooks, playbooks, campaigns, cases, evidence, validation, engagement authorization, and reviews.

Templates define minimum required fields. Remove instructional prompts only after the final record remains complete. Public copies must be sanitized according to [Data Governance](../docs/DATA-GOVERNANCE.md) and the [Evidence Handling Standard](../docs/EVIDENCE-HANDLING-STANDARD.md).

| Template | Use |
|---|---|
| [Runbook](RUNBOOK-TEMPLATE.md) | Repeatable operational procedure |
| [Playbook](PLAYBOOK-TEMPLATE.md) | Incident decisions and coordinated response |
| [Campaign](CAMPAIGN-TEMPLATE.md) | Authorized adversary-emulation sequence |
| [Incident Case](INCIDENT-CASE-TEMPLATE.md) | Investigation and response record |
| [Evidence Log](EVIDENCE-LOG-TEMPLATE.md) | Evidence inventory and custody |
| [Validation Record](VALIDATION-RECORD-TEMPLATE.md) | Controlled test result |
| [Rules of Engagement](RULES-OF-ENGAGEMENT-TEMPLATE.md) | Campaign authorization and boundaries |
| [Post-Incident Review](POST-INCIDENT-REVIEW-TEMPLATE.md) | Lessons and corrective actions |
